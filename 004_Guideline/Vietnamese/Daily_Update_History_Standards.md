## Thay đổi chính（tóm tắt）

- Tên: cập nhật履歴 → **Lịch sử công việc**（`Work_History_`）
- Lưu: `008_Work_history/Japanese|Vietnamese/`
- Format: bảng（Đối tượng／Loại công việc／Tóm tắt）. JP/VN tách file
- Gộp cả team: `Work_History_YYYYMMDD.md` merge theo mã đối tượng
- Prompt: 「作業履歴を作成して」（「日報を作成して」 cũng được）

File format cũ giữ trong `008_Update_history/`（không tạo mới）.
